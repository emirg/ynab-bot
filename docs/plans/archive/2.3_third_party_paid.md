# Plan: Milestone 2.3 - Third-Party Paid Shared Expenses

## Objective & Context
- **Status:** Completed
- **Harness Roadmap Marker:** 2.3
- **Goal:** Allow the parsing and creation of split transactions where the *other* person paid the expense (e.g., "Frank gastó 50k en carulla conmigo").
- **Why:** To improve flexibility. When someone else pays, the user incurs a debt (their share of the expense). In YNAB, this is perfectly represented as a 0-sum transaction in a tracking account (like "Shared Transactions"), where the user's share is an outflow to the target category (e.g., Groceries) and an inflow to the Splitwise person's category (e.g., Frank).

## Proposed Changes

### Domain Models
#### [MODIFY] src/domain/models/expense.py
- Add `payer: str = 'user'` to the `Expense` dataclass parameters (can be `'user'` or `'other'`).
- Update `to_ynab_format()` to handle `self.payer == 'other'`:
  - When the other person pays, `transaction_data["amount"] = 0`.
  - Calculate `user_share_milliunits = int(self.amount * self.split_proportion * -1000)`.
  - Create two subtransactions:
    - Outflow: `{"amount": user_share_milliunits, "category_id": self.category_id}`
    - Inflow: `{"amount": -user_share_milliunits, "category_id": self.split_category_id}`

### Parsers
#### [MODIFY] src/parsers/llm_expense_parser.py
- Update `_generate_message_system_prompt()` to include `"payer": "user" | "other"` in the JSON schema for `shared_expense`.
- Add an instruction in the prompt: `"payer" debe ser "other" si otra persona pagó el gasto (ej. "Juan pagó 50k"), o "user" si el usuario lo pagó.`
- Update the parsing logic to validate and extract `payer`.

### Application Services
#### [MODIFY] src/application/services/expense_service.py
- In `_process_shared_expense`, extract the `payer` from `parsed`.
- Assign `expense.payer = payer`.
- If `payer == 'other'`, retrieve the shared account from `split_config_repository.get_shared_account(telegram_user_id)`.
  - If no shared account is configured, return an error result asking the user to configure it via `/splitwise`.
  - Override `account_id` and `account_name` with the shared account's values.

### Presentation
#### [MODIFY] src/presentation/telegram/formatters.py
- In `ExpenseResponseFormatter.format_success`, check `expense.payer`:
  - If `'other'`, format the message to clarify that the other person paid and how much the user owes, e.g., "🤝 *Pagado por:* {split_person}" and "📊 *Tu deuda ({pct}%):* ${amount} → {category}".
